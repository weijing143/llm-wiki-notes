# AWS Bedrock接入GLM-5.3并按调用量分成（上证报）

> ⚠️ 本页 evidence_level 为 C：财经媒体报道（记者窦世平），关键信息标注“记者从智谱了解到”，接近主体披露但仍属媒体转述链路，未附公告原文，故从严定 C。

来源摘要：中国证券网（上证报）报道，2026-10-06 发布，抓取日期 2026-10-07。检索快照见 `raw/notes/zhipu-aws-bedrock-verify-2026-10-07.md`。

## 关键数据快照

- AWS 官网显示 GLM-5.3 正式进入 Amazon Bedrock，企业客户可经托管 API 调用，支持跨区域推理、Prompt Cache（抓取 2026-10-07）
- “并非简单上架模型”：AWS 基于模型调用量与智谱收入分成（智谱向记者确认）
- 高盛：智谱评级“中性”→“买入”，2026 年底 ARR 预测 27 亿 → 32 亿美元
- 全业务口径 ARR 达 18 亿美元（2026-09-16 披露；本文正文为 JS 渲染，审计时未能直接抓取复核，标为待确认）
- Cursor 上线 GLM-5.3 / GLM-5.3-Flash，称 Max 推理设置下 CursorBench 4.0 开放权重模型最高分（智谱披露口径）
- 背景：Anthropic 2025 年约 46 亿美元收入中约 21.6 亿（47%）经 Amazon / Google 云市场完成（市场消息，未定位一手）
