# 软件工程不是写代码！谷歌DeepMind高管坦言

**Benoit Schillings** 在 AI Engineer World's Fair 2026 上的演讲翻译整理。核心论点：代码生成正在变得免费，但软件工程的总成本不会消失——定义问题、管理复杂度、验证结果、承担上线后果仍留在工程师手里。

## 关键论点

1. **代码变便宜 ≠ 软件变容易** — 3500 万行 PHP 代码库中修改一行，才是软件工程
2. **函数/模块最初为人脑减负** — Agent 时代模块化不消失，服务对象多了 Agent
3. **代码审查转向系统行为** — 没人逐行读 AI 代码后，审查看接口、权限、性能、供应链风险
4. **SWE-bench 测试不足** — 能运行 ≠ 一年后不是麻烦
5. **下一代语言为人？为模型？** — 强类型/形式化方法，不一定对人类友好
6. **代码之后** — 需求可验收、边界可读取、验收有证据、可回滚

## 金句

> "写代码越便宜，为代码负责就越贵。"
