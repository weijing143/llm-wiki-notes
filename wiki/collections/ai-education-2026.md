来源：抖音 @量子位《Anthropic开始授课！所有AI课程免费学》（2026-08-24，1:03）分析 + 官方页面核查（academy.claude.com，2026-08-26）。本页为 **2026-08 时间点快照**，数字为核查时点值。

## 核心结论（核查后）

**视频事实基本属实（4 条中 3 条逐条吻合 A 级、1 条含合理演绎，量子位无标题党）**。Anthropic 于 2026-08-24 前后上线 Claude Academy（academy.claude.com），课程全部免费，分两条线：**AI 素养**（4D 框架 4h 主课 + AI 能力与局限 3.5h + 7 分钟速览）和**产品/开发者**（Claude.ai/Cowork/Code/Tag/Platform，含 API 与 MCP）。战略本质是**生态圈地**：把"从入门就学 Claude"前置到教育环节，与 OpenAI、Google 的免费 AI 教育形成竞争。

## 战略解读

- **教育是新的竞争前线**：Anthropic（Claude Academy）、OpenAI、Google 都在做免费 AI 教育——抢占用户/开发者的"第一课"，把自家生态变成默认选项；
- **与制药布局同逻辑**：收购 Coefficient Bio 做药、上线免费学院做教育——Anthropic 不满足于卖模型，在往上下游占入口（见 [[collections/ai-pharma-2026]]）；
- **对使用者的意义**：第一方免费课程 ≈ 官方产品手册的体系化版本；Claude Code / MCP 课程对开发者可直接上手。
